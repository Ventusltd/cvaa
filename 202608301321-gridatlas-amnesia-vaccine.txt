That is hostile amnesia in a repo: each session's AI built a fresh driver because it
could not see the last one.

=====================================================================
PART 2  HOW THE VACCINE WORKS
=====================================================================
Memory lives in files a machine checks, never in a person or a model.
- STATE.md: generated one-pager; what is live, what is active, what the rules are.
- scope-of-works/: timestamped markdown files, exactly one with status active,
  each naming its successor, so the work is a linked list on disk.
- tools/scope/loop.mjs: lint | next | state | rollback. One script, four verbs.
- .github/workflows/202608301321-scope-loop.yml: wakes every 30 min or on dispatch,
  lints, finds the active scope, regenerates STATE.md, hands Claude Code only those
  two files, requires it to write the successor and mark itself done, commits.
- .github/workflows/202608301321-verify-live.yml: after Pages deploys, polls the
  root until it serves what git says is current, runs the golden path in a real
  browser (repd_ref 13599, Beacon Fen Energy Park), rolls back atlas/current.json
  on failure.
- lint fails on the four regressions amnesia produces: two active scopes, a full
  app copy at the root, a new one-off workflow, a pointer at a release whose
  sha256sums.txt does not verify. The AI has no memory but cannot break structure.

Worked samples
1. Ordinary run: loop finds 02-cartridge-manifest active, agent adds cartridges to
   current.json, writes 03 as successor, flips 02 to done, lint passes, commit.
   Context loaded: about three thousand words.
2. Regression: a later session copies the app to 202609011000-atlas-v9 at root and
   adds a workflow. Lint fails on both, run goes red, nothing pushes.
3. Blocked: scope 3 needs pipelinenews_repo_url, still null. Agent sets blocked,
   writes the reason, commits. Later runs find nothing active and exit in 20 s.
4. Bad promotion: scope 4 ships the postcode cartridge, golden path fails, verify-live
   reverts current.json to its previous commit. Site is back within one deploy.
5. Human returns after two weeks: reads STATE.md and the one active file. Done.

----- tools/scope/loop.mjs -----
#!/usr/bin/env node
// tools/scope/loop.mjs  —  gridatlas scope loop driver, generation 202608301321
// Usage: node tools/scope/loop.mjs lint | next | state | rollback
import { readdirSync, readFileSync, writeFileSync, appendFileSync, existsSync, statSync } from 'node:fs';
import { execSync } from 'node:child_process';

const SCOPE_DIR = 'scope-of-works';
const ATLAS_DIR = 'atlas';
const CURRENT = `${ATLAS_DIR}/current.json`;
const LEGACY_WORKFLOWS = Number(process.env.LEGACY_WORKFLOWS || 25);
const LIVE_ROOT = 'https://ventusltd.github.io/gridatlas/';
const GOLDEN_REPD_REF = '13599';
const RELEASE_RE = /^2026\d{8}-atlas-v\d+$/;

const sh = (cmd, opts = {}) => execSync(cmd, { stdio: 'pipe', ...opts }).toString().trim();
const out = (k, v) => process.env.GITHUB_OUTPUT && appendFileSync(process.env.GITHUB_OUTPUT, `${k}=${v}\n`);

function frontMatter(file) {
  const text = readFileSync(`${SCOPE_DIR}/${file}`, 'utf8');
  const block = text.match(/^---\n([\s\S]*?)\n---/);
  const meta = {};
  for (const line of (block?.[1] || '').split('\n')) {
    const m = line.match(/^(\w+):\s*"?([^"#]*?)"?\s*(#.*)?$/);
    if (m) meta[m[1]] = m[2].trim();
  }
  meta.file = file;
  return meta;
}
function scopes() {
  if (!existsSync(SCOPE_DIR)) return [];
  return readdirSync(SCOPE_DIR).filter(f => /^\d{12}.*\.md$/.test(f)).sort().map(frontMatter);
}
function currentPointer() {
  return existsSync(CURRENT) ? JSON.parse(readFileSync(CURRENT, 'utf8')) : null;
}

function lint() {
  const failures = [];
  const fail = m => failures.push(m);
  if (existsSync(ATLAS_DIR)) {
    for (const f of readdirSync('.')) if (RELEASE_RE.test(f)) fail(`root release folder ${f}; releases live in ${ATLAS_DIR}/releases`);
  }
  const wf = existsSync('.github/workflows') ? readdirSync('.github/workflows') : [];
  const perRelease = wf.filter(f => /^\d{12}-/.test(f) && !/scope-loop|verify-live/.test(f));
  if (perRelease.length > LEGACY_WORKFLOWS) fail(`${perRelease.length} timestamped workflows exceed legacy ${LEGACY_WORKFLOWS}; write a scope file instead`);
  const active = scopes().filter(s => s.status === 'active' && s.scope !== '0');
  if (active.length > 1) fail(`${active.length} active scope files: ${active.map(s => s.file).join(', ')}`);
  for (const s of scopes()) if (s.scope !== '0' && s.parent && !existsSync(`${SCOPE_DIR}/${s.parent}`)) fail(`${s.file} names missing parent ${s.parent}`);
  const cur = currentPointer();
  if (cur) {
    const dir = `${ATLAS_DIR}/releases/${cur.release_id}`;
    if (!existsSync(`${dir}/sha256sums.txt`)) fail(`${dir} has no sha256sums.txt`);
    else { try { sh('sha256sum -c sha256sums.txt --quiet', { cwd: dir }); } catch (e) { fail(`${dir} checksums fail`); } }
    for (const c of cur.cartridges || []) {
      const p = `${ATLAS_DIR}/${c.path}`;
      if (!existsSync(p)) { fail(`missing cartridge ${c.path}`); continue; }
      const have = sh(`sha256sum ${p}`).split(' ')[0];
      if (have !== c.sha256) fail(`cartridge ${c.path} sha256 ${have} != manifest ${c.sha256}`);
      if (statSync(p).size > 400_000) fail(`cartridge ${c.path} over 400 KB; that is an app copy`);
    }
    if (existsSync('index.html') && /2026\d{8}-atlas-v\d+/.test(readFileSync('index.html', 'utf8'))) fail('root index.html still hard-codes a release id; it must forward to atlas/ only');
  }
  if (failures.length) { console.error('LINT FAIL\n' + failures.map(f => '  - ' + f).join('\n')); process.exit(1); }
  console.log('lint ok');
}

function next() {
  const active = scopes().filter(s => s.status === 'active' && s.scope !== '0');
  if (active.length > 1) { console.error('AMNESIA GUARD: more than one active scope'); process.exit(2); }
  if (!active.length) { console.log('nothing pending'); out('pending', 'false'); return; }
  const s = active[0];
  console.log(`active scope ${s.file}`);
  out('pending', 'true'); out('scope_file', `${SCOPE_DIR}/${s.file}`); out('generation', s.generation); out('scope_number', s.scope);
}

function state() {
  const cur = currentPointer();
  const head = sh('git log -1 --format=%h%x20%s');
  const rows = scopes().map(s => `${s.file}  status=${s.status}  scope=${s.scope}  next=${s.next || '-'}`);
  const live = cur ? `${cur.release_id} at ${cur.route}` : 'root index.html redirect (pre-atlas; see releases/current-v5.json)';
  const cartridges = cur?.cartridges?.length ? cur.cartridges.map(c => `  ${c.path}  ${c.sha256.slice(0, 12)}`).join('\n') : '  none yet (scope 2 introduces them)';
  writeFileSync('STATE.md', `# STATE  (generated ${new Date().toISOString()} by tools/scope/loop.mjs; do not edit)

Read this file, then read the single active scope file. Nothing else is required to continue.

Live release: ${live}
Head: ${head}
Golden fixture: repd_ref ${GOLDEN_REPD_REF} must resolve on ${LIVE_ROOT}

Cartridges
${cartridges}

Scope ledger
${rows.join('\n') || '  no scope files'}

Rules enforced by lint
- one active scope file at a time; scope 0 is the master list
- releases live in atlas/releases and are immutable; sha256sums.txt must verify
- new work is a cartridge plus a current.json rewrite, never a copy of the app
- no new timestamped workflows; the scope loop and verify-live are the only drivers
`);
  console.log('STATE.md written');
}

function rollback() {
  if (!existsSync(CURRENT)) { console.log('no pointer to roll back'); return; }
  const commits = sh(`git log -2 --format=%H -- ${CURRENT}`).split('\n');
  if (commits.length < 2) { console.log('pointer has no previous commit'); return; }
  sh(`git checkout ${commits[1]} -- ${CURRENT}`);
  sh('git config user.name gridatlas-verify-live');
  sh('git config user.email actions@users.noreply.github.com');
  sh(`git commit -m "verify-live: roll back ${CURRENT} to ${commits[1].slice(0, 7)}"`);
  sh('git push');
  console.log(`rolled back to ${commits[1].slice(0, 7)}`);
}

const cmd = process.argv[2];
({ lint, next, state, rollback }[cmd] || (() => { console.error('usage: loop.mjs lint|next|state|rollback'); process.exit(64); }))();

      - name: Do exactly one scope

          git config user.name gridatlas-scope-loop
          git config user.email actions@users.noreply.github.com

          git commit -m "scope loop: residue from ${{ steps.next.outputs.scope_file }}" || exit 0

PART 6  LIMITS RESPECTED
=====================================================================
Cron minimum 5 min (loop uses 30). Job timeouts 45 / 20 min under the 6 h cap.
concurrency cancel-in-progress: false so a commit is never killed mid-write.
workflow_dispatch always present because schedules are dropped under load and disabled
after 60 days without commits on public repos. App token expires in 1 h, fine for a
45 min job. postcodes.io is free, unauthenticated and CORS-open with no published hard
limit; cache default and never poll it. Playwright asserts DOM side effects
(body.dataset.gridatlasRepdDeepLink, .maplibregl-popup), never canvas pixels.
