Disease

A family of nine defects that keep returning in different costumes. Each one lets a number, a
verdict or a deployment be reported as established when nothing established it, and each one was
reproduced with a date in this estate on 20-21 September 2026. They are one disease because they
share one mechanism: the absence of evidence is converted into a favourable value instead of a
refusal. A missing key becomes a zero. A missing difference becomes a typed-in "0 differ". A
missing standards file becomes a clause that cannot be tested, so it passes. A gate with no
volume becomes a gate that never fires. A probe with no power becomes a certificate. A repeated
run becomes coverage. A constant with no source becomes a limit. A machine path becomes a
published file. A push becomes a deployment. Every one of them is silent, and every one of them
inflates.

Symptom

D1 a missing key read as a zero: a counter asked for "cases" with a numeric default, so 47 real
runs of 295,770,420,000 cases each were logged as "0 cases" beside a 75 second runtime, and the
published overnight total was understated by 79.9 per cent, 17,391,591,847,800 against a
corrected 31,292,801,587,800. D2 a reassurance that is a string literal: "0 differ" was typed
into a format string and printed identically on 240 log lines whatever the sweep found. D3 a gate
that gets weaker when its evidence disappears: with the standards note unreadable every clause
resolved to a no-standards-file sentinel, the ABSENT test was False for all of them, and
everything PASSED. D4 a gate that can never fail, or can never pass: one tests whether IEEE
arithmetic obeys IEEE, which is permanently true, so its --ci can never pass; a rule with zero
volume never fires and a rule with full volume never discriminates. D5 a count without a
denominator or a miss probability: "0 differ on 200,000 cases" carried a 0.999400 chance of
missing the thing it was looking for. D6 a repetition count presented as coverage: the same
deterministic lattice was re-run 48 times and the counts added, giving 31.29 trillion "cases"
where the distinct space is 661.7 billion. D7 a number with no source: 749 limit sites across 18
values resolve to nothing at all, and two of the four limits everything is measured against have
no source. D8 an absolute path or an account name in a public file: scrubbed twice and re-broken
twice, most recently by the very commit that added the scrub's sibling. D9 committed reported as
deployed: three times in one session "pushed" was reported as "live", and one generation was
pushed, gated, hashed and merged while the served route still carried its predecessor, with
nothing red anywhere, because a 200 on one route is not reachability.

Dose

every-commit, in any repository that carries source, published text or workflows, which is all of
them. The antibody reads only `ctx.loops`, a bounded, data-only snapshot that `inoculate.mjs`
builds: every `.py .mjs .cjs .js .ts .md .txt .rst .yml .yaml` file under 192 KiB up to a 4 MiB
budget, plus, for D8 alone, a scan of every non-binary file under 8 MiB that records LOCATIONS
ONLY. Nothing in the target is imported or executed; no network, no shell, no clock. On this
estate the whole scan is well under a second.

Four deliberate limits, so that this vaccine cannot itself become a D4:

1. It never reads anything under `vaccines/` or `.cvaa/`, nor the registry's own
   `tools/selftest.mjs`, because a vaccine, an immunisation record and the harness that plants
   the disease on purpose must all be free to name the thing they exist to catch. Nothing else
   is exempt, and the exemption is three fixed paths, not a marker any file can claim.
2. D8's patterns are built in the context, not here, and they match the SHAPE of a home directory
   rather than any person's name, so this file names nobody and neither does its output. The
   value is never quoted into a finding, so a CI log from this check is safe to publish.
3. D5 and D6 judge published prose; D1, D2, D3, D4, D6 and D7 judge code. Findings are capped at
   six sites per dose with a count of the remainder, so a diseased repository reports its shape
   rather than drowning the log.
4. D0 fires when the snapshot was truncated or a file was too large, so a partial read can never
   be mistaken for a clean sheet. That is D3 applied to this vaccine itself.

Each dose is a refusal, not advice. The repair is in every case the same shape: make the absence
of evidence produce a refusal. D1 read the key and fail when it is missing. D2 read the verdict
back from the result. D3 add the test that proves the gate refuses with its evidence file removed.
D4 add the case that fails and the case that passes; delete a gate that can do neither. D5 print
the space and the miss probability beside every count. D6 call a repeated sweep's total
evaluations. D7 tag the limit with its source or delete the limit. D8 take the path out and keep
it out. D9 fetch the served bytes and follow a link to them before the word live is used.
