## Why this belongs in CVAA

Learn the Kuiper makes mathematical rules visible through interaction. CVAA addresses a complementary need: retaining checks that can detect a known failure when code changes.

CVAA records a named failure mode, an executable check and its provenance. That provides a useful foundation for reproducible work: readers can inspect what a check covers and the source it applies to. A public diary provides context and navigation; individual executable checks remain in the vaccine registry.

The learning project makes the same distinction useful in public: the formula, the implementation and the visible interaction each need evidence appropriate to the claim. This entry records that connection without declaring a new vaccine or certifying an application release.
