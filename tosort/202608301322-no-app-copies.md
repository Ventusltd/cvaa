Disease
An AI that cannot see how the last release was built copies the whole application into a new timestamped folder rather than adding one module.

Symptom
Eight sibling folders at the repo root each containing the full app: 202608291237-atlas-v9 through 202608300453-atlas-v9.

Antibody
```js
export default ({ rootDirs }) => {
  const copies = rootDirs.filter(d => /^\d{12}-.+-v\d+$/.test(d));
  if (copies.length > 1 || (copies.length && rootDirs.includes("atlas"))) return copies.map(d => `root release folder ${d}; releases belong under atlas/releases`);
  return [];
}
```
